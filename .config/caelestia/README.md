# Caelestia settings

This config runs the customized Caelestia shell through the user service
`caelestia-shell.service`. `shell.json` contains shell preferences, and
`cli.json` connects wallpaper selection to the local image/video wallpaper workflow.

Set your weather location in `shell.json`. The AWCC status icon is disabled by
default; enable it if you use the optional Alienware GUI integration.
